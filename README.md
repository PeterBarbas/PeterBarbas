Started as a software engineer, moved into technical program management, and kept building products alongside — which means I plan roadmaps I could implement myself. My work sits where delivery, engineering reality, and product intent collide: multi-team dependencies, ambiguous scope, and the gap between what a status report claims and what's actually true.

### 🔭 Tracer

**An AI delivery-ops copilot for TPMs.**

The tool I wanted every Monday morning. Tracer reads across **Jira, Slack, and GitHub**, reconciles what each source claims about a program, and surfaces the drift — the ticket marked *in progress* that hasn't moved in nine days, the dependency nobody flagged, the risk that only exists in a thread.

Built on the **Claude API**. My answer to a question I got tired of asking by hand: *what is actually blocked right now?*
