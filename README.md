### 🔧 Tracer — AI delivery-ops copilot for TPMs

The tool I wanted every Monday morning. Tracer reads across **Jira, Slack, and GitHub**, reconciles what each source claims about a program, and surfaces the drift — the ticket that's "in progress" but hasn't been touched in nine days, the dependency nobody flagged, the risk that only exists in a thread.

Built on the **Claude API**. It's my answer to a question I got tired of asking manually: *what is actually blocked right now?*
